# 🚗 3D 模拟驾驶游戏合集 (3D Driving Simulator)

 在线试玩地址：
 https://glsite.com/opengame/cyberpunk_racer_3d.html
 
 https://glsite.com/opengame/countryside_driving_3d.html

这两款游戏均使用PythonStudio内置的智能体助手及deepseek-v4.1-flash模型开发。
基于 **Three.js** 开发的两款 3D 网页模拟驾驶游戏，纯前端实现，无需安装，双击网页即可在浏览器中畅玩。支持键盘与手机触屏双操作。

| 场景 | 游戏 | 文件 |
| :---: | :--- | :--- |
| 🏙️ 城市道路 | **模拟驾驶 · 城市道路** | `cyberpunk_racer_3d.html` |
| 🌾 乡村公路 | **乡村驾驶 · Countryside** | `countryside_driving_3d.html` |

## ✨ 游戏特色

### 🏙️ 城市道路版 (`cyberpunk_racer_3d.html`)

- **双向四车道**，中央隔离护栏，车道对齐行驶
- **十字路口 + 红绿灯**：红灯越线扣 100 分，横向穿行的车辆会撞车判定
- **掉头路段**：中央护栏缺口 + 掉头标志，低速通过 +30 分，超速 -50 分
- **丰富车流**：普通轿车、公交车、警车、校车、救护车同向 / 对向行驶，带跟车避让逻辑
- **真实城市景观**：
  - 程序化生成的建筑立面窗户纹理
  - 8 大品牌类共 **65 个** 商家霓虹招牌（KFC、麦当劳、瑞幸、华为、各大银行…）
  - 楼顶大牌 / 一楼门头 / 楼身中牌多种广告牌
  - 路灯、椰子树、撑伞行人、公交站台、自行车、摩托车
  - 建筑周边花草绿化
- **交通标识**：限速、禁止停车、注意行人、直行/左转指示牌
- **地面标线**：车道导向箭头、"礼让行人"、"公交站台"、"慢行" 大字
- **车头照明**：聚光灯 + 地面光斑

### 🌾 乡村公路版 (`countryside_driving_3d.html`)

- **双向两车道**，可借对向车道超车
- **大弯道**：道路蜿蜒起伏，一侧曲率明显
- **徽派建筑**：白墙黑瓦 + 阶梯马头墙 + 木质门窗
- **田园风光**：
  - 大片农田（近处路旁 + 远处连绵）
  - 戴草帽弯腰劳作的**农民**
  - 桂花树 / 圆冠树成林
  - 起伏**山丘**、远处**小河与桥**
- **白鹭与飞鸟**：天空中有白鹭和成群小鸟飞过，翅膀扇动
- **电子摄像头**：路过时自动拍照闪光 + 快门声
- 车流（含警车/校车/救护车）、对向车辆碰撞判定

### 🌤️ 两款游戏共有特性

- **动态天气系统**：随机晴 / 雨
  - ☀️ 晴天：蔚蓝天空 + 卡通白云 + 彩虹
  - 🌧️ 雨天：阴天 + 雨丝 + 闪电 + 雷声
- **换车功能**：可切换 5 款车型外形
  - 粉色宝马 MINI、特斯拉、小米 SU7、保时捷、奥迪
  - 带品牌车标、后视镜、腰线细节
- **多视角切换**：追尾 / 驾驶舱 / 后视镜视角
- **雨天溅水粒子**、轮胎水花效果
- **实时 HUD**：得分、速度、信号灯状态

## 🎮 操作说明

### 键盘操作

| 按键 | 功能 |
| :---: | :--- |
| `↑` / `W` | 加速 |
| `↓` / `S` | 减速 |
| `←` / `A` | 向左变道 |
| `→` / `D` | 向右变道 |
| `空格` | 刹车 |
| `C` | 切换视角 |

### 手机 / 触屏操作

屏幕已内置虚拟按键：
- **左侧十字键**：`▲` 加速 / `▼` 减速 / `◀` 左转 / `▶` 右转
- **右侧按钮**：`换车` / `C`（视角）/ `刹车`

> 📱 手机建议横屏游玩，并点击右上角面板的信息条保持视野开阔。

## 🚀 如何运行

无需任何构建工具或服务器，**两种情况都可用**：

1. **直接双击** 对应的 `.html` 文件，用浏览器打开即可。
2. 或在浏览器地址栏输入文件路径，例如：
   ```
   file:///C:/你的路径/Projects/cyberpunk_racer_3d.html
   ```

### 环境要求

- 现代浏览器（推荐 **Chrome / Edge** 最新版）
- 支持 WebGL
- 需要联网（从 CDN 加载 Three.js）

## 🛠️ 技术栈

| 技术 | 用途 |
| :--- | :--- |
| **Three.js r128** | 3D 渲染引擎 |
| **HTML5 Canvas** | 程序化生成纹理（招牌、建筑立面、路面文字、鸟/白鹭、车标） |
| **Web Audio API** | 引擎声、雷声、快门音效 |
| **CSS3 / Pointer Events** | UI、虚拟按键、响应式 |
| **原生 JavaScript** | 游戏循环、物理、AI 逻辑 |

> 全部为单文件实现（HTML + CSS + JS 内联），无需额外依赖。

## 🎯 玩法提示

- **遵守交通规则**：别闯红灯、别撞车、掉头路段减速
- **利用变道躲避**：观察前方车流，提前变道
- **速度与得分**：速度越快得分越高，但风险也越大
- **雨天注意**：雨天能见度降低，注意车距

---

## 🔧 可自定义参数

游戏内多处逻辑参数可调，例如：

- `CURVE_AMP` / `CURVE_FREQ`：弯道幅度与频率（乡村版）
- `maxSpeed` / `baseSpeed`：速度范围
- `totalCarCount` / `spawnTimer`：车流密度
- `BRANDS` 数组：自定义商家招牌品牌

找到对应变量修改数值后保存，刷新浏览器即可生效。

## 📝 开发说明

- 所有 3D 模型、纹理、招牌、鸟类、建筑等均由代码**程序化生成**，不依赖外部资源文件。
- 场景采用「循环滚动」技术模拟无限前进的道路，物体在后方回收复用到前方。
- 弯道通过「按 z 位置横向偏移」曲线函数实现，元素随位置自然弯曲。
